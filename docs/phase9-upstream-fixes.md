# Phase 9 — Upstream fixes: global side effects and broken references

Fixes the Critical items C1–C10 from [upstream-review.md](upstream-review.md) and removes the code that pointed at content missing from 1.20.1.2. This phase has not been load-tested yet.

## Broken references removed

**Great Ming** (an optional compat layer for a mod we don't support):
- **Removed:**
  - **Decisions:** the Ming government menu (`ucm_daming_ming_gov_menu_decisions.txt`), `change_sansi_government` and the `zhuge_sansi` open/close menu decisions.
  - **Ming currency menu:** the `zhuge_daming_currency_menu` interaction, the `zhuge_curry_interactions` events and the `HQ_change` effect.
  - **Reform menu:** `ucm_government_reform_events.txt`, which nothing could open, plus its `ucm_chenzhi_*` menu effects.
  - **Government code:** `ucm_government_bianshen_daming_effects/triggers.txt`, the 10 `gm_*` trigger localizations, the Ming court-position stubs, the Ming sand-soldier tab (28 tiles, 14 spawn branches, 28 catalog entries), and the compat triggers `ucm_compat_daming_loaded_trigger` and `ucm_is_gm_yan_*`.
- **Simplified callers:** the governor purge and grant triggers, the purge skill values and the merit trigger. Behaviour without Great Ming is unchanged.
- **On_actions:** removed `zhuge_uec_on_actions.txt` and `ucm_tgp_glue_on_actions.txt`, which deleted the other mod's globals at game start and every year. Also removed the Ming part of `zzz_ucm_compat_probe.txt` and the comment-only `zzz_ucm_daming_ming_gov_menu_probe.txt`.
- **Localization:** removed 299 Ming lines across all languages, plus the `zhuge_curry_menu_events_l_*` files.
- **Main menu:** removed three buttons; the menu is regenerated by `tools/gen_ucm_main_menu.py`.

**Titular titles:** the 8 `ucm_authority_title_*`, `ucm_expansion_title_*` and `ucm_titular_supremacy_*` files (effects, triggers, modifiers) and `ucm_authority_title_post_grant_bootstrap_effect`. Their 10 `e_/k_ucm_*` titles were never defined, and nothing called them.

**Dragon page:** `dp_char_editor.514/.515`, its menu option and the `dp_char_editor_dragon_birth` key. It used 13 AGOT-only traits.

**Japan administrative: kept.** The review said `japan_administrative_government` was missing from 1.20.1.2. That was wrong: it is defined on line 1 of vanilla `common/governments/01_japan_government_types.txt`, after a BOM. Every government the mod now references exists in vanilla.

## Follow-up after the first load test

The load test came back at 725 errors at the main menu (995 in Phase 8) and 853 with a save loaded (1,091). Three months of play added none. These are the follow-up fixes:

| Was | Now |
| --- | --- |
| `ucm_chenzhi_target_vassals` / `ucm_chenzhi_force_mass_feudal` "used but never set", left over from the deleted reform menu | The 12 mass-conversion limits and the feudal-conversion branches that checked them reduce to their real condition. No behaviour change |
| Realm succession menu: 8 checks of a game rule that doesn't exist, and 6 checks of `innovation_visigothic_codes` / `innovation_theme_system`, which aren't in 1.20 (28 error lines) | Innovation gating removed: the options are always shown. The "unlock innovation" page (`.1010`) and its loc are gone. The opener decision now uses the same conditions as the event (not landless, not administrative) |
| "Only me" and "Me and vassals" set the new law flag without clearing the old one, so the quarterly enforcement kept reapplying the old law | New `realm_rse_flag_cleanup` effect (next to `gender_rse_flag_cleanup`), called before every flag is set. It also replaces 12 copy-pasted blocks |
| 28 traits set as both genetic and with an `inherit_chance` | `genetic = yes` dropped. They keep their explicit chance and parent sex (e.g. 30%, male line) |
| 20 traits marked `good` that are neither genetic nor inherited | `good = yes` dropped. It only affects genetic display |
| `category = intrigue` / `stewardship` (not valid categories) | Removed |

## Checks run

- Every edited file has the same BOM state and net brace balance as before, and no stray CR bytes.
- 351 definitions were removed (from deleted files and removed blocks). The only remaining references are to the vanilla `dynasty_of_many_crowns_decision` and the generic word `widget`.
- A sweep for Great Ming identifiers (`e_greatming`, Ming governments, `Data_tuiju`, `hq_check`, `ming_city_holding`, …) finds nothing left in `common/`, `events/`, `gui/`, `localization/` or `tools/`.
