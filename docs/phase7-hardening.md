## Localization

- The menu's 372 text keys are translated into German, Russian, Simplified Chinese and Turkish (`localization/<lang>/ucm_l_<lang>.yml`). They're generated by `tools/gen_ucm_translations.py`, which stops if an English key has no translation. Every data function (`[...]`) is checked to match the English.
- The mod-information texts in all five languages no longer describe a "GitHub test build".

## Load test

Run on CK3 1.20.1.2 with only this mod, to the main menu.

- **First run: 2,723 error entries.** Removing the full English debug-text override exposed 14 debug keys the baseline also defines in `ucm_character_interaction_menus_l_*.yml`. These, plus two older duplicates (`strong_test_hook`, `UNCATEGORIZED_ACTIONS`), now live only in `localization/replace/<lang>/ucm_debug_l_<lang>.yml` in all five languages. Also, the new truce button lacked the `name` that `add_truce_both_ways` requires; it now has one (`ucm_truce_name`).
- **Second run: 2,706 error entries**, against the 2,717 Phase 0 baseline. No duplicate localization keys, and no errors from any `ucm_` menu file (scripted GUIs, effects, triggers, events, window).

The load test checks every script, text and GUI file. It doesn't click buttons, so the in-game checklists in the phase notes still apply.
